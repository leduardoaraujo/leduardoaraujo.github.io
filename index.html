GAV Insights

copiloto corporativo

Copiloto que responde perguntas em linguagem natural sobre o ecossistema analítico da empresa: escolhe o relatório certo, consulta o Power BI e mostra o resultado. Antes de responder, verifica regras de negócio e permissões. O motor de retrieval é open-source: OpenContext.

Python · React · Power BI · Fabric · PostgreSQL · SQL Server · CosmosDB · MCP · RAG · DAX

pipelinekit

framework de dados

Framework ETL para ingestão de APIs, com pipelines declarados em YAML: chamadas assíncronas, transformação de JSON e entrega simultânea para múltiplos destinos.

Python · asyncio · FastAPI · PostgreSQL · DuckDB · Airflow

Lab OCR Engine

visão computacional

OCR local-first para documentos fiscais brasileiros. Preserva blocos, coordenadas e incerteza. A validação é determinística; o LLM entra só para estruturar trechos específicos.

Python · PaddleOCR · OpenCV · Pydantic · Typer · pytest

OpenDecision

modelo de decisão

Classificador que escolhe a próxima ação de um agente a partir de uma descrição do estado atual. Devolve a probabilidade de cada ação e pede revisão humana quando a mais alta fica abaixo de um limiar. O gráfico mostra a saída real do exemplo de passagens aéreas: a ação certa venceu, mas com pouca confiança, então o caso vai para revisão.

Python · scikit-learn · TF-IDF · joblib
